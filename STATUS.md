# Motif build update

**Works now (in automated tests):** a person rests for 10 seconds, picks a comfortable movement, practices it, passes separate checks and an "everyday activity" check, then approves it. The movement alone can then pick phrases, build and speak a message, pause, change speed and recalibrate. Up to four movements can work together (for example one moves to the next item, one selects, one pauses), and each new movement is checked so it doesn't get in the way of the others. If the face is lost or the tab is hidden, nothing gets selected. A Space-bar mode is there for people who can't use a face movement. A browser test with a fake test camera passes.
